# DAC音频适配万用板焊接说明

依据已经确定的Pocket Lab-F1 DAC1衰减隔直方案，2026-11-02绘制。此图不更改FPGA程序。

图纸：[电路原理图](audio_adapter_schematic.png)、[元件面与焊接面布局](audio_adapter_perfboard.png)。

适用条件：2.54mm孔距、每孔独立焊盘的万用板，能放下24列×16行区域（孔中心跨度58.4×38.1mm），通常5×7cm板可用。若是连条铜箔板，不能直接照此焊接。行号A～P、列号1～24为本图自定义坐标，请先在板边标记；不是厂家印字或FPGA管脚编号。

## 放置元件（从元件面看）

| 元件 | 数值 | 第一脚 | 第二脚 |
|---|---|---|---|
| R1 | 10kΩ，1/4W | D3 | D7 |
| R2 | 1kΩ，1/4W | I7 | N7 |
| C1 | 2.2μF无极性CBB，≥25V | D10 | D21 |
| R3 | 1kΩ，1/4W | J14 | J18 |
| R4 | 1kΩ，1/4W | L14 | L18 |
| R5 | 100kΩ，1/4W | I10 | N10 |

电阻与无极性CBB均不分方向。确认电容为225（2.2μF），不是224或222。实物CBB脚距若不匹配D10/D21，可用短绝缘线连接这两个孔，不强掰引脚；电容固定后不能挤压其他焊点。

## 背面逐点连线

绕板的竖直中轴左右翻面，反面列号左到右变成24～1，行号仍从上到下A～P。照图纸第二部分焊线，不按正面左右位置猜。

| 网络 | 要连通的孔/路径 | 用途 |
|---|---|---|
| IN | D2—D3 | 输入到R1 |
| A | D7—D10；D7—I7 | R1、R2、C1共同节点 |
| B | D21—G21—G10—I10；在G14接向J14、L14 | C1、R5、R3、R4共同节点 |
| L | J18—J23 | R3到左声道 |
| R | L18—L23 | R4到右声道 |
| GND | N2—N7—N10—N23 | 公共信号地 |

以上每一项为独立网络，不同项之间不能直接焊接连通。特别是A/B之间必须经过C1，B/L之间经过R3，B/R之间经过R4。B支路的G14—L14必须焊接J14处的R3引脚。
彩色连接可拆成若干短绝缘线，剥皮部分只接到指定焊盘；连接经过的无关孔无需焊接。浅灰元件投影不是连接线。

## 接外部线

| 板上孔 | 外部连接 |
|---|---|
| D2 | DAC1转接线的信号导体 |
| N2 | DAC1转接线的信号地/同轴屏蔽层 |
| J23 | 3.5mm TRS母座L端，接插头Tip |
| L23 | 3.5mm TRS母座R端，接插头Ring |
| N23 | 3.5mm TRS母座GND端，接插头Sleeve |

DAC转接线及端子实际脚序需看实物和通断测量，不能仅凭线色、端子从左到右的位置判断。3.5mm插头Tip为尖端、Ring为中环、Sleeve为靠线缆的套筒。此处不使用TRRS四极接口。
DAC2不接。万用板不接12V或3.3V；它是无源电路。音箱必须有源且有AUX/LINE IN模拟输入，按音箱规格单独供电。

## 焊接、检查、首次接入

1. 板卡、音箱均断电，先测各电阻阻值，再放元件、焊背面连接。
2. 先不要接DAC和音箱，用通断档检查每个网络内部连通，目视排查焊锡桥接；不同网络间应经过对应元件。
3. 仍不接DAC和音箱，电阻档参考：D2到N2约11kΩ；J23到L23约2kΩ；J23到N23、L23到N23分别约101kΩ。电容充电会使读数暂时变化，等待稳定再判断，考虑电阻和仪表误差。这些检查不能取代所有逐点检查。
4. 确认电路无误后接DAC1信号与地，暂不接音箱。程序只写SRAM时，断电后需要重新下载当前已验证的码流。
5. 用示波器1MΩ输入检查A点及音箱端的幅度、频率和波形；地夹只接信号GND，不开50Ω终端。输出稳态直流应接近0V；普通万用表不能代替音频幅度/削顶检查。
6. 初始以约0.1Vpp的小信号检查音箱输入端，实际幅度由测量和音箱输入规格决定。A点空载分压1/11不等于所有音箱都能承受。
7. 检查通过后将音箱调到最低音量，连接L/R/GND，再逐渐提高音量。插拔或下载前静音。最后固定电容、线缆并绝缘焊点。
