# 双输出版实物验收与比赛演示

适用：2026-11-03 top_dual，DAC1 + USB460800；不是旧单独USB或30秒DAC版。
本表是验收操作流程，不代表全部实物项目已通过。已确认的是两端同时发声及停止电脑播放后DAC仍可演奏。

## 准备

1. 下载Type-C、独立串口Type-C按现有方式连接电脑；板卡和有源音箱正常供电，DAC1沿现有衰减隔直电路接音箱AUX。
2. 板卡若断电过，重新下载 dual_audio/impl/pnr/f1_dual.fs，使用SRAM Program and Verify，确认Verify success。不要误下旧单独版。仅写SRAM的程序不会因重新上电自动保留。
3. 演示开始前按一次K8复位；这会清空录音并恢复中八度、关闭琶音。正式录好后不要再按K8。
4. 按仓库 README 安装 Python 依赖并运行 `host/player.py`，选择实际 CH340 串口、460800 和电脑声音输出设备；先20%音量，再按需要调节。音箱自身也从较低音量起调。
5. SW1/2设正弦，SW3设短包络，SW4切演奏页。SW逻辑0/1不是对物理ON方向的推断，按实物页面确认。
6. 先松开所有K键，再开始。演奏页K1~K7是音符，控制页同一组键是命令。每次切页都先全部松键，每个控制键单独按下并松开。

## 开关与显示速查

| 开关/按键 | 当前双输出版用途 |
|---|---|
| SW1=0，SW2=0 | 正弦，音色显示0 |
| SW1=1，SW2=0 | 方波，音色显示1 |
| SW1=0，SW2=1 | 三角波，音色显示2 |
| SW1=1，SW2=1 | 回退正弦，不是第四种音色 |
| SW3=0/1 | 短/长包络 |
| SW4=0/1 | 演奏页/控制页 |
| 控制页K1/K2 | 降/升八度；显示0低、1中、2高 |
| 控制页K3/K4 | 琶音开关/速度循环（1中→2快→0慢→1中） |
| 控制页K5 | 无片段时开始录制；录制中停止保存；已有片段时保护它 |
| 控制页K6 | 回放/停止；录制中一次按下即可停止保存并立即回放 |
| 控制页K7 | 清空录音 |
| K8 | 全局复位并清空录音 |

演奏页的四项为声部数、音区、包络、音色；控制页为状态、音区、琶音开关、速度。数码管物理左右顺序以实物对应为准，勿仅按“左起第几位”猜。
控制页状态0空闲、1录制、2回放、3自动到限。D1~D7显示实体琴键，D8显示有活动声部，尾音和回放时D8仍可亮。

## 完整验收（约10~15分钟）

逐项填写“通过/未通过”，有问题记录操作、音色、音区和使用哪条输出。

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 单音 | 演奏页，K1~K7依次按、松，重复两轮 | 每键有声，音高依次升高；松键后尾音结束，无挂音 |
| 三音色 | 每次全松键，再切正弦/方波/三角，各弹同一组K1、K3、K5 | 能分辨音色变化，无明显破音；切换后重新按键验证 |
| 四复音 | 琶音关闭，按住K1+K3+K5，再加K7，保持约2秒；依次松开 | 听见叠加和弦；四个声部可同时工作；全部松开后恢复静音 |
| 八度 | 控制页K1降至0，切演奏页弹K1；再控制页K2到1、2，分别弹K1；最后恢复1 | 同一琴键低/中/高明显不同，每升一档升一个八度；边界不越界 |
| 包络 | 琶音关闭；短包络和长包络各重新按住K1约1秒后松开 | 起音、持续音量与尾音有区别；最终均静音 |
| 琶音 | 控制页K3开启；演奏页按住K1+K3+K5；再在控制页K4切速度后重试 | 三音依次循环；中/快/慢速度变化明显；全松键后停止；最后K3关闭 |
| 录制回放 | 按下方《小星星》流程操作 | 状态1→2→0，按原顺序回放，无中途缺段或挂音 |
| 片段保护 | 已有片段，控制页按K5，再K6回放 | 不重新开始录制，不覆盖旧片段，仍可重放 |
| 回放停止/清空 | 回放中控制页K6停止；松键后K7清空，再K6 | 停止后尾音结束；清空后旧片段不能再次回放 |
| 仅DAC | 音箱开启，电脑播放器点停止，弹奏 | DAC继续发声 |
| 仅USB | 外部音箱关闭或静音，播放器开始，弹奏 | 电脑继续发声 |
| 双路 | 音箱和播放器均开启，弹奏及回放 | 两边都能听到；允许电脑缓冲造成延迟差，不作为同步故障 |
| 串口恢复 | 先停止播放器，拔独立串口数据线，保持下载口供电，弹DAC；再接回并开始播放器 | DAC持续可演奏；USB重新开始后恢复；若COM变化，重开播放器选择新端口 |
| K8复位 | 仅在录音可丢弃时按K8 | 声部停止，录音清空，中八度且琶音关；尾音/电脑旧缓存结束后不挂音 |

串口稳定性另测：复位后重新点击播放器停止/开始，连续演奏或回放5分钟，校验错误/缺包应保持0，缓存不持续增长，缓冲异常不持续增加。K8会重置串口序号，不能把复位引起的序号重置和稳定运行丢包混算。
可选容量验收：空片段开始录制，保持录制直到120秒自动停止，状态3表示已保存，K6应可回放。2048事件也可能先到限，不能承诺琶音一定录满120秒。

## 录制《小星星》（按键编号就是简谱数字）

准备：中八度1、琶音关、任选音色，建议正弦或三角。每个数字按一下再松开，同音重复也要松开再按；每行最后一个音延长一拍。

```
K1 K1 K5 K5 K6 K6 K5—
K4 K4 K3 K3 K2 K2 K1—
K5 K5 K4 K4 K3 K3 K2—
K5 K5 K4 K4 K3 K3 K2—
K1 K1 K5 K5 K6 K6 K5—
K4 K4 K3 K3 K2 K2 K1—
```

1. 控制页，全松键，K7清空，松开后K5开始录制，确认状态1。
2. 松开K5，切演奏页，全松键，再弹上面的旋律。建议每拍约0.4~0.5秒。
3. 弹完全部松键，切控制页，全松键，直接按K6，状态2并立即回放。
4. 回放结束状态0；要重放再K6。要重录必须先K7再K5。
5. 若出现状态3，表示已自动保存，直接K6回放，不要把K5当作清空。

## 比赛现场建议顺序（约3分钟）

1. 20秒：只开DAC音箱，弹K1~K7；说明FPGA合成，直接经板载DAC输出。
2. 30秒：同一短旋律切三音色；松键后再切，方便听出变化。
3. 20秒：K1+K3+K5和弦，再加K7演示四声部。
4. 30秒：演示低/中/高八度，然后开启琶音，按住K1+K3+K5，演示一个速度变化。
5. 50秒：关闭琶音、恢复中八度；现场录制《小星星》前两行，K6停止并回放，双手离开琴键展示。
6. 20秒：重放同一片段，开启电脑播放器；短暂展示双路，然后关闭外部音箱展示仅USB；最后停止电脑播放、打开音箱展示仅DAC。

演示主讲时建议只留一路声音，双路用作功能展示即可。不要把约40ms软件缓存说成已经实测的总延迟，不宣称双路声学同步，也不要把三种波形说成真实钢琴/小提琴音色。

## 常见现象

- 控制页K1不发音：正常，该页K1是降八度。
- D8亮：代表活动声部，松键尾音和回放也会使其亮。
- 数码管声部数松键后短暂不为0：ADSR尾音还未结束。
- 音色/八度切换后旧音不立刻变：先松键再按，新音才使用新设置。
- 有包但没电脑声音：查播放器输出设备、音量、系统音量及声音幅值是否非0。
- 两边同时响有回声：电脑缓冲引起，正常功能测试分别听，主讲保留一路。
- 断电后功能不对：重新下载双输出f1_dual.fs；K8复位不能代替重新烧录。
